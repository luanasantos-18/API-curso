# API-curso 

Projeto de estudo desenvolvido durante meu aprendizado em **Java e Spring Boot**.

O projeto utiliza o domínio de **eventos** como contexto para praticar o desenvolvimento de uma API REST, trabalhando com persistência de dados, PostgreSQL, JPA/Hibernate, organização em camadas e versionamento do banco de dados com Flyway.

> **Projeto de estudo:** desenvolvido para colocar em prática os conhecimentos adquiridos durante o curso. O domínio de eventos foi utilizado como contexto de aprendizado e não representa experiência profissional na área.

---

## Objetivo

O principal objetivo deste projeto é colocar em prática conceitos de desenvolvimento backend utilizando Java e Spring Boot.

Durante o desenvolvimento, estou aprendendo e praticando:

* Criação de APIs REST;
* Organização de aplicações Spring Boot;
* Persistência de dados com JPA/Hibernate;
* Integração com PostgreSQL;
* Criação e gerenciamento de migrations com Flyway;
* Utilização de DTOs;
* Separação de responsabilidades entre as camadas da aplicação;
* Versionamento do código utilizando Git e GitHub.
